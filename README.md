# 软考题库

面向 [码上创](https://vb.csdn.net/)「考试」场景的静态 H5。目录按 2026 年软考全年资格排列，本轮可刷的是高级五科，以及已迁入的中级「软件设计师」。

## 可刷资格

| 等级 | 资格 | 题量 |
|------|------|------|
| 高级 | 信息系统项目管理师 | 289：2023 版大纲 269 个末级考点 + 案例 12 + 论文 8 |
| 高级 | 系统分析师、系统架构设计师、网络规划设计师、系统规划与管理师 | 各 36，尚未按大纲铺全 |
| 中级 | 软件设计师 | 57（综合知识） |

其余中级、初级资格在首页可见，标记为即将上线。

## 用法

1. 选等级，再选资格。
2. 用科目（综合 / 案例 / 论文）和章节筛选。
3. 揭晓后标记会了或不会。不会的题会提高再抽权重。
4. 导出今日战报。图上带资格名，以及综合、案例、论文的今日复习数。

进度按资格存在本机 `localStorage`，键名 `ruankao-flash-v2.{资格 id}`。

## 本地打开

```bash
cd src/ruankao-flash
npx --yes serve -p 5173
```

浏览器访问 http://localhost:5173
